# Tanimawo AI for Windows: download

The **Tanimawo AI Academy** student app for Windows 10 and 11. It is the app at
[app.tanimawoai.com](https://app.tanimawoai.com) in its own window: Code Lab, My Websites, Connect, notifications and
everything else, and you stay signed in.

## ⬇️ Download

**[Download for Windows (.exe, 111 MB)](https://github.com/Samsontanimawo/Tanimawo-AI-Windows/releases/latest/download/Tanimawo-AI-1.0.7-win-x64.exe)**

(Windows 10 or 11, 64-bit. All releases: [Releases](https://github.com/Samsontanimawo/Tanimawo-AI-Windows/releases).)

## Install

1. Open the downloaded file `Tanimawo-AI-…-win-x64.exe` (double-click it, or click it in your browser's downloads).
2. Windows may show **"Windows protected your PC"** (the app is not signed with a paid certificate yet).
   Click **More info**, then **Run anyway**.
3. Choose where to install (the default is fine) and click **Install**. No administrator password is needed.
4. Open **Tanimawo AI** from the desktop or the Start menu, and sign in.

If your browser says the download "isn't commonly downloaded", choose **Keep** (in Edge: the **…** menu → **Keep** →
**Keep anyway**).

To remove it: Settings → Apps → Installed apps → Tanimawo AI → Uninstall.

## Updates

The app always shows the latest version of the Academy app, so you do **not** need to download again for new lessons
or features. From version 1.0.3 the app also **updates itself**: when a new version comes out it downloads it quietly
and asks you to **Restart now** (or it updates the next time you close it). You stay signed in. You can also choose
**Help → Check for updates**. If you have 1.0.2 or older, download 1.0.7 once; after that, updates come to you.

(`latest.yml` and the `.blockmap` file in each release are for these automatic updates; you only need the `.exe`.)
